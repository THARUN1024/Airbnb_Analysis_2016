## Overview

This project analyzes Airbnb listing data from 2016 using Tableau for visualization. The dataset includes listings and calendar data, providing insights into pricing trends, revenue patterns, and price distributions across zip codes. The goal is to help stakeholders make data-driven decisions regarding property investments, pricing strategies, and market analysis.

## Skills Used

- **Data Analysis**: Analyzed Airbnb listing data to extract meaningful insights on pricing, revenue trends, and geographic pricing patterns.
- **Tableau**: Created visualizations including bar charts, choropleth maps, and line graphs to represent data trends effectively.
- **Data Cleaning**: Processed and joined the listings and calendar datasets to create a unified dataset for analysis.

## Key Insights

1. **Average Price Per Bedroom**:  
   - The average price for a **1-bedroom property** is **$96.2**.  
   - The average price for a **6-bedroom property** is **$584.8**.

2. **Price Distribution by Zip Code**:  
   - The zip code **98177** has the highest average price of **$842**.  
   - The zip code **98122** has the lowest average price of **$122.3**.

3. **Revenue Trends for 2016**:  
   - Significant growth in revenue was observed during peak seasons of 2016.
